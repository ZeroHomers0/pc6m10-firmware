# 双语界面渲染维护说明

## 当前布局

- 6P 设置菜单共 9 项，索引为 `0..8`；语言选择是第 9 项。
- 6P 不显示、也不能进入仅 12P 使用的“电流手动平衡”。
- 所有完整菜单行必须覆盖 16 个 LCD 字符列；不同菜单页之间导航时先清屏再重画，避免短行、空白行和反显背景残留。

## 数值与单位列

- 参数标签占列 `0..10`，数值域占列 `11..14`，单位固定在列 `15`。
- 四位数天然覆盖整个数值域；三位数和有符号角度只占三列，渲染后必须清列 `14`。
- 数值函数不得清列 `15`。原厂显示序列会在数值之后独立绘制 V/A/S/% 等单位；保留这些
  A/B 可证明的调用，但不在编辑超时擦除路径中重复补画。
- 该规则同时解决短数字跨页残留（例如 `169` 后显示 `0`）和单位被擦除的问题。

## 中英文字形

- `9.语言选择` 的中文从偶数列 `2` 开始，使用标准 16×16 路径即可。
- 6P 不保留奇数列汉字专用渲染器；若菜单编号或前缀改变，必须重新检查中文起始列。

## 回归要求

修改显示代码后至少运行 `test/static/test_bilingual_ui.py`、完整测试、构建和 Unicorn A/B 验证，并实机检查菜单翻页、单位列、选中背景及中英文切换。
