# W8 硬件实测执行清单

> 本文件是 W8 硬件执行和判定的唯一来源。软件安装、J-Link 命令、Modbus 脚本和仪器菜单操作见
> `W8_SOFTWARE_OPERATION.md`；离线证据见 `W8_PRE_HARDWARE_VALIDATION_2026-08-23.md`。
> **必检项完成状态以 `W8_TEST_MASTER.md` 为准**（本文档为流程规范细节，不含进度）。

## 1. 总体放行规则

严格按阶段 0→4 推进。任一必检项失败或未确认，立即停止，不得跨级。

| 阶段 | 范围 | 进入下一阶段的条件 |
|---|---|---|
| 0 | 上电前与可恢复性 | CRP 已确认；原固件双备份哈希一致；功率级和门极隔离 |
| 1 | 控制电冒烟 | 无异常复位/HardFault；SWD 可重连；继电器无误动作；栈水位合格 |
| 2 | 三相同步与空载触发 | 过零、相序、12°/60°、停机和保护撤销触发全部通过 |
| 3 | Modbus 与 ADC 标定 | 只读通信正常；reg44/45 双点标定及掉电保存通过 |
| 4 | 低压限流，再到带载 | 前述全部通过；具备隔离、急停、保险和持证电工条件 |

## 2. 安全前提

- 阶段 0–3 断开市电、高压主回路、SCR 门极驱动和实际负载，使用隔离限流控制电源。
- 未确认原固件可恢复前，严禁 `Unlock`、`Recover`、`Mass Erase` 或任何擦写。
- 普通示波器探头不得测量强电；阶段 4 必须使用额定合适的差分/隔离探头并由持证电工操作。
- P12 排针（全）：1=VTref、2=GND、3=P2.10(ISP 引导，低进 bootloader)、6=SWDIO、7=nRESET、8=SWCLK；仅接 SWD 时用 1/2/6/8。
- J-Link 的 VTref 只作参考，不能作为控制板主电源。

## 3. 硬件与关键点

必需：J-Link、隔离限流电源、万用表、≥2 通道示波器、三路 120° 可控同步源、USB-RS485、
已知电压/电流参考源。阶段 4 另需差分探头、保险、硬件急停和合适的低压负载。

P12：1=3.3V VTref、2=GND、3=P2.10/ISP、6=SWDIO、7=**nRESET**、8=SWCLK。**P12-7 有 RESET#**，
connect-under-reset 直接拉 P12-7 即可，不需另接 MCU 复位网络。所有调试信号均为 3.3V 逻辑。

触发引脚：G1–G6=P0.17/P0.15/P0.18、P2.9/P2.19/P2.16；12 脉波扩展=P2.8/P2.7/P2.6/
P2.5、P0.8/P0.7；三相过零输入 EINT1/2/3=P2.11/P2.12/P2.13。

| 时序 | 50 Hz | 60 Hz |
|---|---:|---:|
| 12° 脉宽 | 666.7 μs | 555.6 μs |
| 60° 间隔 | 3.333 ms | 2.778 ms |

## 4. 阶段 0：上电前与备份

- [ ] 核对 MCU 为 LPC1765、P12 方位和 3.3V/GND 连通关系。
- [ ] 功率级、门极、负载和市电已物理断开；控制电源限流值已记录。
- [ ] J-Link 以 SWD 100 kHz 连接，读取 `0x000002FC` 的 CRP 字。
- [ ] 连续读取两份 256 KiB 原 Flash，分别计算 SHA-256，二者完全一致。
- [ ] 备份存放在两个独立位置，不提交到公共仓库。
- [ ] 已演练恢复命令，但尚未执行任何擦写。

通过：上述全部完成；若 CRP 导致不能读取完整固件，停止并评估，不得解锁。

## 5. 阶段 1：控制电冒烟

- [ ] 烧写前再次核对当前固件 SHA-256。
- [ ] 门极和功率级仍隔离，仅上控制电；记录静态电流。
- [ ] 复位后无 HardFault、异常复位或持续看门狗循环，SWD 可以重新连接。
- [ ] LCD、按键、EEPROM、认证和 RS485 基本工作。
- [ ] 监测 P0.20/21/22、P1.20..23，上电及复位期间继电器无危险误吸合。
- [ ] 用 SRAM 哨兵测得中断负载下的最低 MSP 水位，并保留安全余量。

通过：所有控制功能可重复，且恢复原固件路径仍有效。

## 6. 阶段 2：三相同步与空载触发

正式验证必须提供三路 50/60 Hz、相差 120° 的隔离同步信号。单路输入只允许验证中断响应，不能
判定三相时序。直接注入 MCU 侧时，先用示波器确认电平始终位于 0..3.3V。

- [ ] 核对 EINT1/2/3 的频率、相序、电平和下降沿。
- [ ] 逐路记录 G1–G6，必要时再测 12 脉波扩展。
- [ ] 脉宽符合 12°，相邻触发间隔符合 60°，相序正确。
- [ ] 给定变化时，触发时刻按 `触发角=180°−当前角` 单调变化。
- [ ] 停机、急停、过压、过流和缺相均能及时撤销触发，且无残留窄脉冲。
- [ ] 波形与 `TIMER2.MR0`、运行状态和故障状态交叉记录。

通过：全部波形和保护路径通过；任何一路异常都不得进入负载阶段。

## 7. 阶段 3：Modbus 与 reg44/45 标定

先执行只读测试。reg61 涉及继电器，只有在继电器输出已确认安全并显式启用写测试时才能写。

| 寄存器 | 物理量 | ADC | 标定除数 |
|---|---|---|---|
| reg44 | IF 输出电流反馈 | AD0.3 | reg54，合法范围 3500..4500 |
| reg45 | Uf 输出电压反馈 | AD0.4 | reg55，合法范围 3500..4500 |

- [ ] 以默认 9600 8N1、从站地址 1 只读 reg40–45；若无响应先核对板内参数。
- [ ] 分别向 Uf/IF 前端施加两个已知参考点，记录真值、ADC/寄存器值和误差。
- [ ] 调整 reg54/55 后误差达到约定范围，且两个参考点均保持线性。
- [ ] 掉电重启后 reg54/55 保留，reg44/45 仍在误差范围内。

通过：通信、双点标定、合法范围和掉电保存全部通过。

## 8. 阶段 4：低压限流与带载

先从隔离低压、最小导通角和严格限流开始，同时记录三相过零、门极脉冲、负载电流和故障输出。
确认低压行为后才可评估强电带载；强电测试必须另行完成风险评估和作业许可。

立即停机条件：相序错误、门极常导通、保护未撤销触发、继电器误动作、电流失控、异常复位或测量
接地不明确。
