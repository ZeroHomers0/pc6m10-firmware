## 问题：产品版本信息屏"厂商:XIANPOWER"的 X/O 不显示

**现象**
case9 产品版本信息屏（`MENU==9`）厂商行 `XIANPOWER` 的 **X 与 O 渲染为空白**。
原厂串是 `SINEP0WER`（数字 0），故原厂从未暴露；2026-09-01 定制为 `XIANPOWER` 后暴露。

**根因**
原 BIN 8×8 ASCII 字库仅 36 字符（map @0x10000BB8 =
`0123456789%:. +IVUAWSBP-DCRc,M*FHTEN`，无 X(0x58)/O(0x4F)）。`disp_render_char8`
（OLD 入口 0xB44 / NEW 0xBA0）查表未命中直接 `return`，X/O 渲染空白。
与 PC12M-2 完全同源（同 36 字符集，map @flash 0x12369 已核验无 X/O）。

**修复方法**
方案C（与 12p 同款，A/B 最安全——不动 ram_data_image / 字库 / 链接布局）：

1. `firmware/src/02_lcd_display.c` 新增 `ext_char8_xo[0x20]` 扩展字形表
   （X/O 各 0x10 字节，与原字库同格式：8 列 × 2 页、列高字节 bit7=行首）。
2. `disp_render_char8` 对 `ch==0x58/'X'`、`ch==0x4F/'O'` 提前匹配，指向扩展字形表；
   其余字符仍查原字库（字库外字符保持空白，如 'Z'）。
3. 两处 `disp_data` 取字从 `DAT_00000fc0 + tbl_idx*0x10` 改为 `gbase + tbl_idx*0x10`。

**为什么不在 map 加字符**：map 槽区无空位（早前验证，同 12p 结论）。

**验证**
- A/B 全套 PASS：TIMER1_MATRIX 126、OUTPUT_STAGE_MATRIX 144、STATE_MACHINE_MATRIX 130、
  DISPLAY_MATRIX 106、DISPLAY_FULL_EXEC 4、MODBUS 65 读/320 写等全部 PASS。
- 新增 `XO_FONT`（PAIRS OLD=0xB44 / NEW `disp_render_char8`）：
  - OLD 'X' → **0 次** GPIO 写（原厂确实空白，基线证明）
  - NEW 'X' → 387 次 GPIO 写、NEW 'O' → 387 次（渲染生效）
  - NEW 'Z'(0x5A 字库外) → 0 次（空白保留，回归护栏）
- `test/run_tests.py` 静态测试全 PASS。
- **性质**：对本固件的**有意定制偏离**（原 BIN 渲染 X/O 为空白）；A/B 快照区无差异，
  仅"渲染 X/O 字符"的 GPIO 写迹与 OLD 不同（OLD 不写）。case9 本就不在 A/B 矩阵。
