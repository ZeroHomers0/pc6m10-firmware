## 1. 系统架构（已完全确证）

```
┌────────────┐  RS485/Modbus   ┌──────────────────────────┐  I2C @0x53   ┌──────────────────┐
│  上位机    │◄───────────────►│ LPC1765 (UART3)          │◄────────────►│ EEPROM@0x53     │
└────────────┘                 │  · live RAM 0x100016xx    │              │ 24C02 类 256字节 │
  旋转编码器/菜单 ─────────────►│  · shadow 0x1000166x+     │  参数非易失存储  │  (被动参数存储)  │
                               │  · 同步器 FUN_000035f2    │              └──────────────────┘
                               │  · ADC0 测量 / 闭环计算   │
                               │  · 认证门控 FUN_000106a0 ──P2.1-2.4→ADuM1201──► 隔离侧(防克隆)
                               │  · 输出时序 TIMER2.MR0 (EINT3 每输入过零编程)
                               │  · 使能 P0.20 / 停机 P0.21/22 + P1.20-23 + P4.28/29 ──► 外部功率电路(功率转换)
                               │  · 输入过零 EINT1/2/3 = P2.11/12/13 (下降沿, EXTINT)
                               └──────────────────────────┘
```

- LPC1765 在 RAM 维护"实时参数"(live) + "影子镜像"(shadow)。
- `FUN_000035f2`(0x35F2)：对 61 组参数，`if (live != shadow) { shadow=live; i2c_write_reg(...) }`，逐组推送到芯片。
- `load_config`(0x25DC)：开机双银行 magic 校验（reg5/6=='U'=0x55 银行A，reg7/8=='f'=0x66 银行B），读回芯片→影子→live。
- I2C 器件：7-bit 地址 **0x53**（写 0xA6 / 读 0xA7）。
- **I2C 是 GPIO 位带模拟**（无硬件 I2C0 引用，见 §4f）：**SDA=P0.10 / SCL=P0.11**（FIO0 bit10/bit11），辅助函数 0x1C40-0x1EBC。
- `i2c_write_reg`(0x1E88)：`[0xA6][reg][val]`+STOP；`i2c_read_reg`(0x1EBC)：`[0xA6][reg]`→restart→`[0xA7]` 读 1 字节。
- **芯片@0x53 = 24C02 类被动串行 EEPROM**（§4g.A，130+ 读全在 load_config，运行期零读回）。
- **LPC1765 无本地 PWM/DAC 外设，但用 TIMER2(0x40090000) 编程 SCR 触发角定时**（§4f/§4j）：EINT3 每个同步过零把闭环结果换算成 TIMER2.MR0（8 组 BASE 常数），经**触发脉冲 GPIO（G1-G6=P0.17/15/18/P2.9/19/16 + 12脉波 P2.8/7/6/5/P0.8/7，12° 脉宽/60° 双脉冲）**驱动外部三相晶闸管桥；运行/报警/备用继电器=P0.22/21/20；状态 LED=P1.20-23；认证经 ADuM1201(P2.1-2.4) 隔离链路（硬件印证，见 HARDWARE_VERIFICATION）。

## 4b. ADC0 测量链路（FUN_00001fbc，主循环每轮调用 2 次）★本次核心确证

> 关键技巧应用：`DAT_00002310..DAT_000025dc` 字面量池全部从 bin 直读解析。

**ADC0 外设**：基址 **0x40034000**（AD0CR=0x40034000，AD0DR=0x40034004）。
- 12-bit 结果：`(AD0DR & 0xffff) >> 4`（FUN_00001fa6，自旋等 DONE 位 bit31）
- 启动转换：`AD0CR |= 0x1000000`（FUN_00001f80）
- 通道选择：`AD0CR = (AD0CR & 0xffffffc0) | SEL`（SEL=1<<ch）

**每次调用流程**：递增采样计数 `0x100015C4`(0..5 循环) → 连续采集 **6 通道**（顺序 ch2,ch1,ch0,ch5,ch3,ch4），各自存入 6 深环形缓冲 → 仅对"计数匹配的通道"做 **5 点移动平均**（0x100015C0 暂存）→ 按该通道的**标定除数**换算 → 写对应测量寄存器。

**环形缓冲**：ch2@0x1000213C、ch1@0x10002178、ch0@0x100021B4、ch5@0x10002268、ch3@0x100021F0、ch4@0x1000222C（索引=采样计数）。

**标定公式**（param4=0x10001640，gain_a=0x1000163C，gain_b=0x10001638）：

| 计数 | 通道 | 平均 | 测量寄存器 | 物理信号（硬件 AD0.x 引脚） | 公式 |
|---|---|---|---|---|---|
| 0 | ch2 | 5点@0x10002150 | **reg41** (0x10001598) | **IA**（AD0.2=P0.25） | `(param4 × avg × 2) / reg51` |
| 1 | ch1 | 5点@0x1000218C | **reg42** (0x1000159C) | **IB**（AD0.1=P0.24） | `(param4 × avg × 2) / reg52` |
| 2 | ch0 | 5点@0x100021C8 | **reg43** (0x100015A0) | **IC**（AD0.0=P0.23） | `(param4 × avg × 2) / reg53`；0x100015A4=avg 副本 |
| 3 | ch5 | 10点@0x1000227C | **reg40** (0x100015A8) | **Ug 给定**（AD0.5=P1.31） | `(avg10 × 101) / 400`；按 param56 选标度 → 0x100015B4 |
| 4 | ch3 | 5点@0x10002204 | **reg44** (0x10001594) | **IF 输出电流反馈**（AD0.3=P0.26） | `(gain_b × avg) / reg54`；0x100015AC = avg×101/400 |
| 5 | ch4 | 5点@0x10002240 | **reg45** (0x10001590) | **Uf 输出电压反馈**（AD0.4=P1.30） | `(gain_a × avg) / reg55`；0x100015B0 = avg×101/400 |

> **采集顺序（本会话反编译 FUN_00001fbc 复现）**：`AD0CR=(AD0CR&0xffffffc0)|SEL`，依次 SEL=4→2→1→0x20→8→0x10（ch2,ch1,ch0,ch5,ch3,ch4），每通道自旋等 DONE 读 AD0DR。**reg↔物理通道唯一映射（任务#14 确证，呼应硬件 AD0.x 接线）**：reg41=IA、reg42=IB、reg43=IC、reg40=Ug、reg44=IF、reg45=Uf。

**ch5 (reg40) 标度选择**（param56 = 0x1000165A）：
- ==0：reg40 上限 1000；`<10 → 0`
- ==1：`<205 → 0`；`>204 → (x-200)×5>>2`；上限 1000
- 然后按 gain_sel：`0x100015B4 = (gain_a 或 gain_b) × 0x100015C0 / 0xf78(3960)`（gain_sel==0→gain_a，==1→gain_b）

**清零门**：`cfg_word(0x10001628)==0 && 结果<10 → 结果=0`（防零点漂移）。

**结论**：
1. **regs 51-55（3500..4500）= ADC 各通道满度标定除数**（ch0→reg53, ch1→reg52, ch2→reg51, ch3→reg54, ch4→reg55）。把 12-bit 原始 ADC 码换算成工程测量单位。**不是输出设定字**。
2. **regs 40-45 = 实时测量值**（任务#14 物理通道确证：reg41/42/43=IA/IB/IC、reg40=Ug 给定(AD0.5)、reg44=IF(AD0.3)、reg45=Uf(AD0.4)）。reg40=ch5=Ug 给定（外部给定 AD0.5=P1.31，主显示/闭环参考/远程回显），**reg44=IF 输出电流反馈、reg45=Uf 输出电压反馈**（ch3/ch4 闭环反馈，报警阈值 param15/param13 比对；**HARDWARE_VERIFICATION §四.6 待测项已解决：reg44=IF、reg45=Uf**）。
3. 每 6 次调用（≈3ms@0.5ms/次）每个测量寄存器刷新一轮。5 点平均 + 10 点平均抑制噪声。

## 4c. 输出级链路（FUN_0000e9ac，每 10 拍执行一次）★本次核心确证

> 字面量池 0xEDA8-0xFBE0 全部解析。FUN_0000e9ac 读 reg40(0x100015A8) 5+ 次 = 闭环参考源。

**门控**：`0x100015CE==1` 跳过；计数器 0x10002078 每 10 拍执行一次（≈5ms）。

**限幅基准**：
- `0x10002004 = 0xB4(180) - param54(0x10001660)`；`==0 → 1`
- `0x10002008 = 0xB4 - param9(0x10001650)`

**基准 duty `0x10002040`**（gain_sel 分模式）：
- gain_sel==0（恒压）：`0x10002040 = gain_b(0x10001638) / 0xf(15)`
- gain_sel==1（恒流）：`0x10002040 = gain_a(0x1000163C) / 15`
- gain_sel==2（开环）：`0x10002050 = (param6(0x10001644)×1000) / gain_b`；`0x10002040 = gain_b / 15`

**闭环软起动**（`cfg_word(0x10001628)==1 && reg40(0x100015A8)>=10`——**门控读 reg40 读回源 0x100015A8，不是 src(0x100015D0)**，0xEA58-0xEA5E `ldr r0,[0xede0]` 反汇编确认），状态机 `0x10002000`：`0→4→5`
- 起动延时：0x1000207C 计数 >0x5DC(1500) → 0x10002080=1
- phase 4（爬坡积分）：
  ```
  0x10002068 = ((0x2C88 - (0x10002004×0x18bd)/100) / 0x32) / param7(0x1000164C)   // 斜坡速率

  若 ((0x10002054×0x2F8)/100 + 0xEDD < 0x10002070) 或 (reg44(0x10001594)≥param6(0x10001644) 且 gain_b(0x10001638)≥param6) 或 (0x100015B4<0x100015B8) → phase 5

## 4d. 写多寄存器 0x10 路径（FUN_0000b2e0）★确证

> 处理器 = FUN_0000b642 @0xE19E：校验 → 循环调 `FUN_0000b2e0(值指针, 寄存器号=reg-1)`。
> FUN_0000b2e0 落点映射从 bin 直读字面量池解析（0xB4B8-0xB5A0 + 0xB984-0xB9C4）。

**校验**（与写单 0x06 不同）：
- `buf[1]==0x10`（功能码）、`buf[2]==0x10`（组标记）——不满足 → 异常码 1/2
- `start_reg = buf[3]`：==0 或 >0x3e(62) → **异常码 2**（合法 1..62）
- `count = buf[4..5]` 大端：==0 或 >0x3e(62) → **异常码 3**（合法 1..62）
- `buf[6]` 字节数必须 == count×2 → 否则**异常码 3**
- **逐寄存器值无范围校验**（写单有 0..N 边界）→ 可写任意值
- 成功后**不调用 FUN_000035f2**（写单总调用）→ 值靠主循环后续同步到芯片

**落点映射**（case=reg-1）：

| 63 | 无 case | 静默忽略（只读） |

**字节/字宽度**：按参数本性选择 `strb`（byte 参数：reg1/7/8/9/10/11/13/15/17/19-21/23-25/38/46…）或 `str`（word 参数）。值以 `hi<<8|lo` 存 32 位暂存后写入。

**结论**：0x10 写多是"**无范围校验的通用 RAM 写入**"——reg 24/25、27-32、37/38、40、44-46 与写单行为**不一致**：
- reg40 经 0x10 可**直接改写测量值**（0x100015A8），绕过 src_value 语义。
- reg27-29 经 0x10 **无法**校准 ADC（写 scratch 无效）。
- reg24/25 经 0x10 直接改活动增益对（本地生效，不落组4槽/不同步芯片）。
> **写单 0x06 才是"正确"参数设置通道**；0x10 更多是调试/批量读写的通用后门。

## 4e. 闭环链 FUN_00010f0a → FUN_000108b0 ★确证（衔接 §4c 计划项#6）

  ```
  (0x10002108 × 0x1000211C × 10 × (0x1000210C + 0x10002110×-2 + 0x10002114)

## 4g. 芯片@0x53 型号识别 + 开机认证芯片 ★确证（任务#8）

### A. 芯片@0x53 = 被动串行 EEPROM（24C02 类，256 字节）

**决定性证据**：`i2c_read_reg`(0x1EBC) 的全部 **130+ 次调用点都位于 `load_config`（开机加载）内**（0x25E8-0x32D2）。运行期**从不读回**芯片状态，只写参数/计数/状态码。

| 证据 | 说明 |
|---|---|
| 读全在开机 | 仅 load_config 读回参数 → 纯非易失存储 |
| 字节寻址协议 | 写 `[0xA6][reg][val]`+STOP；读 `[0xA6][reg]`→restart→`[0xA7]`+读1字节 —— 与 24Cxx 完全一致 |

| 双银行+magic | reg5/6='U'(0x55)、reg7/8='f'(0x66) 为固件自管初始化标记 |

## 4j. 中断驱动输出架构：EINT + TIMER0/1/2 ★本会话重大发现（任务#11）

> 本会话首次全面反汇编 EINT1/2/3_IRQHandler + TIMER0/1/2_IRQHandler + timer1/2_init + eint3_init + pin_config。
> **核心勘误：0x40090000 = TIMER2（标准 LPC1765 定时器），不是"外部功率电路接口"。TIMER2 是输出时序外设。**

### A. LPC17xx 定时器/外中断基址

| 外设 | 基址 | 用途 |
|---|---|---|
| TIMER0 | 0x40004000 | 系统节拍（MR0=1999，约 20ms@100MHz 预分频） |
| TIMER1 | 0x40008000 | **SCR 触发脉冲生成**（自载 MR0 扫描 240 步，6 窗口×40 步，§4j.E/§4k） |
| TIMER2 | **0x40090000** | **触发角定时**（每次输入过零由 EINT3 重编程 MR0，单次匹配启动 TIMER1 触发序列） |
| EXTINT | 0x400FC140 | EINT1/2/3 边沿锁存（写 1 清零：EINT1=bit2、EINT2=bit4、EINT3=bit8） |
| SYSCON | 0x400FC000 | PINSEL/EXTMODE(0x148)/EXTPOLAR(0x14C) |

**定时器寄存器偏移**：IR=+0（写1清）、TCR=+4（bit1=复位、bit0=运行）、PR=+0x10、TC=+0xC、MCR=+0x14（3=匹配中断+复位）、MR0=+0x18。

### B. EINT 引脚与模式锁存（= **相序自检测**）★本会话补充

- **EINT1=P2.11(TV)、EINT2=P2.12(TU)、EINT3=P2.13(TW)**（PINSEL2 bits 26-31），下降沿触发（EXTMODE bit3=边沿、EXTPOLAR bit3=下降）。
- **相序自检测链**（本会话反汇编确认，§4k 汇总）：
  - EINT1(TV)：EXTINT|=2（清挂起）；**仅当 input_state(0x10002076)==0 时置 =2**；置 eint1_flag(0x100020C0)=1
  - EINT2(TU)：EXTINT|=4；**仅当 input_state==0 时置 =1**；置 eint2_flag(0x100020C1)=1
  - EINT3(TW)：EXTINT|=8；input_locked(0x10002000)==0 时 mode_byte(0x10002075)=input_state（1 或 2）、input_state=0；置 eint3_flag(0x100020C2)=1
  - **TU 先到 → input_state=1 → mode_byte=1（mode1 序列）；TV 先到 → input_state=2 → mode_byte=2（mode2 序列）**——三相电压相序自动识别，两组触发序列适应正/逆相序接线。
- 标志位 eint1/2/3_flag 被 state_machine（0x4a00 区）读取用于界面状态显示。
- **输入锁相**：input_locked 取值范围 0..7，闭环启动后 2..7（FUN_0000e9ac 门控判定 `2≤input_locked≤7`）。

### C. EINT3_IRQHandler（0xFA2C）= 输出定时编程 ISR ★核心

每个输入交流过零（P2.13 下降沿）执行：

1. **锁存模式**：input_locked==0 时 mode_byte=1/2 → input_state=0
2. **频率监测/故障**（debounce_count 0x10001FFA 递增，>9 清零后检查一次）：
   - phase_cnt(0x10001FF9，TIMER0 计数，1MHz 节拍)∈(0x60,0x68)=[0x61..0x67]（97-103）→ freq_hz(0x10001FF8)=0x32('2'=50Hz)
   - phase_cnt∈(0x51,0x56)=[0x52..0x55]（82-85）→ freq_hz=0x3C('<'=60Hz)
   - **失配计数**：`phase_cnt<0x61||>0x67` 且 freq_hz==0x32 → hold_count(0x100020C4)++；`phase_cnt<0x52||>0x55` 且 freq_hz==0x3C → hold_count++；**>4 次连续失配 → 缺相/频率故障**：freq_hz=0、cfg_word=0、gpio_outputs_set()、清 0x10002068/6C/70、out_setpoint=0、fio0_pin22_ctrl()+fio1_pin22_ctrl(0)、input_locked=0、0x1000203C=0、out_param|=0x2000
   - 正常：phase_cnt=0（记录后清零）
3. **门控判定**：`2≤input_locked(0x10002000)≤7 && out_param(0x10001624)==0 && freq_hz≥0x32(50)` → 编程 TIMER2；**否则 gpio_outputs_set()（安全态，不编程）**
4. **编程 TIMER2**（字面量 0x1000C=0x40090000）：
   ```
   TIMER2.TCR=2（复位）;  TIMER2.IR=0xFF（清中断）;
   TIMER2.MR0 = out_freq_adj(0x1000162C)×10 + BASE + out_fine(0x10001654)×K − out_scale(0x100020CC);
   TIMER2.MCR=3;  TIMER2.TCR=1（运行）
   ```

**8 组 BASE 常数**（out_phase 0x1000165B × 频率 50/60 × mode1/2；本会话勘误原表 out_phase 0-3 映射错误）：

| out_phase | 50Hz（mode1 / mode2） | 60Hz（mode1 / mode2） |
|---|---|---|
| 0 | 0x1800 (6144) / 0x1814 | 0x11D7 / 0x11EB |
| 1 | 0x2AB5 / 0x2AC9 | 0x20AF / 0x20B9 |

K 系数：50Hz → 0x38(56)、60Hz → 0x33(51)。
out_scale(0x100020CC)：= out_setpoint×0x58/0x50/0x80(<<7)/0x70 再 /10000，钳位 0x2730/0x23A0/0x3903/0x31E0；out_div(0x1000205C)=(0x2731/0x23A1/0x3904/0x31E1−scale)×10 / 0x22D/0x1FB/0x32B/0x2C5（按 phase0/1×50/60Hz 四组）。

**参数语义（任务#11 解析完成 + 硬件印证）**：
- **out_freq_adj(0x1000162C)**：菜单可调 69..688，芯片 reg 0xC9/CA（2 字节），×10 参与公式 = **触发角定时粗调**（50/60Hz 输入工频相关）。
- **out_fine(0x10001654)**：Modbus reg10，菜单项"10.主从偏移"（40..160=100±60°），×K(56/51) 参与公式 = **触发角定时微调（相移实现）**；同时是开机认证挑战字节源之一（FUN_000106a0）。
- 设备为**三相晶闸管移相触发控制板**：公式输出 = 从同步过零到触发点的**触发角延时**；12° 脉宽/60° 双脉冲波形由软件在触发 GPIO（§G）上产生（详见 `HARDWARE_VERIFICATION_2026-08-20.md`）。

### D. TIMER2_IRQHandler（0xFF48）= 触发角到点 → 启动触发序列 ★本会话修正

- 清 TIMER2.IR、TIMER2.TCR=2（复位，单次匹配不再重载）——**TIMER2 是单次触发角延时**。
- **scan(disp_scan 0x10002074)=0**（触发相位计数器复位到周期起点）。
- **启动 TIMER1**（0x10030=0x40008000）：TCR=2、IR=0xFF、MR0=0x36(54)、TCR=1——TIMER1 开始 240 步触发脉冲扫描（§4k）。

### E. TIMER1_IRQHandler（0xFF6C）= **SCR 触发脉冲生成 ISR**（非显示扫描！）★本会话重大修正

> **推翻旧结论**"TIMER1=12864 LCD 显示扫描"。本会话反汇编确认：TIMER1 ISR 逐次扫描 **scan(0x10002074) 0..240 步**，每步对触发 GPIO 做 SET/CLR，生成 6 窗口 SCR 触发脉冲序列（§4k 全表）。12864 LCD 由 P1 口驱动（DB0-7=P1.0/1/4/8/9/10/14/15，RS=P1.27、E=P1.28、CS1=P1.25、CS2=P1.26，背光 P1.24），刷新在 state_machine 主循环（FUN_0000e9ac 链）完成，非 TIMER1 ISR。

流程（每次进入）：
1. TIMER1.IR=0xFF（清中断）、TCR=2（复位定时器）
2. **scan++**（0..240）
3. **MR0 自载**：
   - scan%40==0（每窗口最后一步）：freq_hz=='2'(50Hz)→MR0=0x488(1160)；freq_hz=='<'(60Hz)→MR0=0x261(609)【窗口边界长导通，见 §4k】
   - 否则 → MR0=0x36(54)【载波步进，54μs，9.26kHz 载波】
4. scan≤0xF0(240) → TCR=1（继续扫描）；scan>0xF0 → scan=0（周期结束）
5. 按 scan 所在窗口(1..240)+mode_byte 选择 4 个触发引脚 SET/CLR（§4k 全表）

### F. TIMER0 = 系统节拍

- timer0_init：MR0=1999、MCR=3、TCR=1（~20ms 节拍）
- TIMER0_IRQHandler(0x29A)：tick_ready=1、phase_cnt(0x100015C8)++（上限 200）、tick_countdown--

## 4k. SCR 触发脉冲生成机制（12°/60° 硬件规格的固件实现）★本会话完整破解（任务#13）

> 设备硬件规格：6 脉波主桥 + 12 脉波扩展，单脉冲 12° 脉宽、双脉冲 60° 间隔。本会话在固件层完整还原其实现：**TIMER2 单次触发角延时 → TIMER1 扫描生成 6 窗口脉冲序列**。

### 时序总览

```
输入过零(EINT3, 每 60°) ──► TIMER2.MR0 = 触发角延时（§4j.C）
        │
        ▼ 匹配中断
TIMER2_IRQHandler: scan=0, 启动 TIMER1(54μs 步进)（§4j.D）
        │
        ▼
TIMER1_IRQHandler: 每步 scan++（0..240），按窗口+mode 对 4 个触发引脚 SET(偶)/CLR(奇)（本 §）
        │  scan=40,80,...,240（窗口边界）→ MR0=1160μs(50Hz)/609μs(60Hz) 长导通
        ▼
scan>240 → scan=0，等待下个过零重新编程 TIMER2
```

### 脉冲宽度与 12°/60° 规格的对应

- **双脉冲 60° 间隔 ✓**：6 窗口×40 步×1.5°=360°，窗口=60°，窗口边界重复触发上一窗口门极 → 双脉冲间隔 60°。
- **载波脉冲**：偶 SET/奇 CLR，54μs 宽（≈1.5° 内 50% 占空），等效 12° 电角度内多次重触发（HEF40106+变压器整形后门极持续导通）。**固件无显式 12° 常量**——12° 由载波+变压器积分等效，或窗口边界长导通实现（见下）。
- **窗口边界长导通**：scan=40,80,...,240（窗口最后一步）MR0=1160μs(50Hz)/609μs(60Hz) 保持当前 SET 电平 —— 对应角度 ≈20.9°(50Hz)/13.2°(60Hz) 的单宽触发，确保晶闸管可靠导通。这是硬件"12° 脉宽"最接近的实现（示波器实测验证项，HARDWARE_VERIFICATION §四.1）。
- **PCLK=1MHz**（§4j.F 反推）：MR0=54→54μs、1160→1160μs；每步 1.5° = 54μs@50Hz（20ms/360°=55.6μs，近似）。

### 封锁/安全态

- 触发角编程门控失败（input_locked<2||>7 / out_param!=0 / freq<50）→ **gpio_outputs_set()**：全部触发 GPIO（G1-G6+P12-G1~G6）置高 = 封锁态（物理极性待实测，§G）。
- 缺相/频率故障（§4j.C）→ 同 gpio_outputs_set + 停机链。

|---|---|---|---|---|
| scan_run_stop (0x19C6) | P0.28/P0.27（FIO0PIN） | 50 (0x32) | 7=RUN / 8=STOP / 0=无 | RUN/STOP 按钮去抖；结果存 0x1000157A |

### E. 结论

固件侧所有 FUN_ 函数均已命名（Ghidra 库 `search FUN_00` = 0 命中）。**主控制路径与全部辅助函数 100% 覆盖**。剩余仅为状态机菜单参数→闭环参数的精确映射细节（PID 低速/中速/快速/自定→芯片 0x6E-0x72、相位限制/主从偏移→out_phase 选择逻辑），属"已理解机制、待逐菜单项确认"级别，非代码盲区。

## 8. 方法论要点（本次验证过的技巧）

- **范围校验提取**：`/tmp/extract_ranges2.py` 从 uart3_disasm.txt 提取每个写 handler 的 `cmp`/`movw+cmp` 边界。注意剔除 `buf[2]==0x10` 标记检查和寄存器号检查；`movw r1,#imm; cmp r0,r1` 形式要单独识别。
- **字面量池解析**：反汇编里 `ldr r1,[0x0000xxxx]` 的字面量值不在 disasm 转储里，直接读 `LPC1765.bin` 对应 flash 偏移 4 字节（小端）。RAM 地址形如 0x1000xxxx。
- **读表/写表不对称**：读表 FUN_0000af94 用 switch(param_2 & 0xfff)，写表用 53 个顺序 if。两者寄存器编号相同但个别读写落点不同（reg 24/25/27-29/37）。
- **xrefs 验证**：`get_xrefs_to <RAM地址>` 确认谁读谁写；对字面量地址（flash 内）也能查，但只能看到引用处，看不到值。
